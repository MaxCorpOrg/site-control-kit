# Linux-пакет

## Назначение

Папка описывает Linux-установку, desktop-файлы, метаданные и запуск продукта.

## Правила и проверки

- используйте стандартные системные пути, не путь домашнего каталога автора;
- сохраняйте режим локального хаба `127.0.0.1` по умолчанию;
- не включайте runtime и браузерные профили в пакет;
- проверяйте синтаксис shell через `bash -n`;
- сверяйте команды с `docs/LINUX_PRODUCT_INSTALL_RU.md`.

Частая ошибка — пакет работает из исходного дерева, но не после чистой
установки.
