# Инструкция для агента

## Цель папки

Сборка установщика Windows и его графических ресурсов.

## Как работать

Проверяйте сценарий оболочки через `bash -n`, а итоговый установщик — на чистой Windows-среде.

## Ограничения и частые ошибки

Не считайте успешную сборку на Linux доказательством работоспособности Windows-установки. Не вшивайте абсолютные пути.
