# Инструкция для агента

## Цель папки

Планировщик сессий для переносимого Telegram Desktop: цели, сообщения, синхронизация и сохраняемое состояние.

## Как работать

Разделяйте модели, построение плана, выполнение и связь с переносимым профилем. Новое поведение сначала оформляйте как план без выполнения.

## Ограничения и частые ошибки

Не отправляйте сообщения при предварительном просмотре. Не обходите ограничения частоты и список разрешённых целей.
