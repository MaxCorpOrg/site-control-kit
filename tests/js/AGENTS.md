# Инструкция для `tests/js`

## Назначение

Быстрые тесты чистых функций семантического DOM и транспортной политики без
запуска Chrome.

## Как работать

Экспортируйте только тестируемую чистую функцию или загружайте модуль в
изолированном контексте. Названия тестов пишите по‑русски.

## Ограничения

Не пытайтесь имитировать весь DOM вручную: iframe, события и service worker
проверяет настоящий E2E.

## Частые ошибки и проверка

Node не имеет browser globals. Проверяйте отсутствие скрытой зависимости и
запускайте `node --test tests/js/agent_dom.test.mjs tests/js/transport.test.mjs`.
