# Инструкция для агента

## Цель папки

Набор правил, матрица проверок и шаблон машинного состояния для агента Telegram.

## Как работать

Используйте `PLAYBOOK_RU.md` для выбора сценария, а `VERIFICATION_MATRIX_RU.md` — для проверки изменённого слоя.

## Ограничения и частые ошибки

Не записывайте реальное состояние поверх шаблона и не подменяйте этим пакетом `docs/PROJECT_STATUS_RU.md`.
