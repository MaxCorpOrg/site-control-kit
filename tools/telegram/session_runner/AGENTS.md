# Инструкция для агента

## Цель папки

Пользовательская оболочка планировщика сессий переносимого Telegram Desktop.

## Как работать

Начинайте с примера настройки и предварительного плана. Реальное выполнение разрешайте только для явно заданных целей и правил сообщений.

## Ограничения и частые ошибки

Не превращайте предварительный просмотр в отправку и не обходите ограничения частоты.
