# Инструкция для агента

## Цель папки

Русское описание архитектуры платформы Telegram и подключения новых инструментов.

## Как работать

Сверяйте манифесты, реестр и команды с `tool_platform/`. Любой пример должен проходить текущую проверку реестра.

## Ограничения и частые ошибки

Не описывайте планируемое как готовое и не используйте английский термин без русского пояснения.
