# Инструкция для агента

## Цель папки

Короткие исполняемые обёртки экспортёра Telegram.

## Как работать

Обёртка должна только найти корень приложения, передать аргументы и вернуть код завершения основного сценария.

## Ограничения и частые ошибки

Не дублируйте здесь бизнес-логику и не задавайте пользовательские пути жёстко.
