# Инструкция для агента

## Цель папки

Пользовательская оболочка безопасного управления приглашениями согласованных пользователей.

## Как работать

Следуйте `ONE_USER_FLOW_RU.md`; статус пользователя меняйте только после явного результата и сохраняйте план, запись выполнения и проверку.

## Ограничения и частые ошибки

Не добавляйте несогласованных пользователей, не скрывайте частичный сбой и не путайте приглашение в чат с добавлением в личные контакты.
