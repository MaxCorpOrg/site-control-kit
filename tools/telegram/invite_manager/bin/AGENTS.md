# Инструкция для агента

## Цель папки

Исполняемые обёртки менеджера и исполнителя приглашений Telegram.

## Как работать

Передавайте управление основным сценариям из `scripts/` без изменения их контракта и кода завершения.

## Ограничения и частые ошибки

Не добавляйте автоматическое подтверждение опасных действий и не храните состояние рядом с обёрткой.
