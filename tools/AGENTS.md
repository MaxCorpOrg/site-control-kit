# Инструкция для агента

## Цель папки

Видимые пользователю инструменты, подключаемые к общей платформе.

## Как работать

Каждый инструмент держите в собственной папке с манифестом, кратким описанием и локальной инструкцией агента.

## Ограничения и частые ошибки

Не размещайте здесь изменяемые данные пользователя и не связывайте инструменты прямыми импортами без платформенного контракта.
