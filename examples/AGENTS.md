# Инструкция для агента

## Цель папки

Минимальные примеры команд и тестовая HTML-страница для браузерного контура.

## Как работать

Один файл должен показывать один сценарий. JSON обязан соответствовать `docs/API.md`, а браузерный пример — запускаться без внешней сети.

## Ограничения и частые ошибки

Не добавляйте токены, личные данные и хрупкие селекторы без пояснения. При изменении формата команды одновременно обновляйте пример, схему агента и тест.
