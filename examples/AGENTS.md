# Инструкция для `examples`

## Назначение

Минимальные JSON payload и локальный HTML‑стенд браузерного E2E.

## Как работать

Один JSON показывает один сценарий. HTML не зависит от внешней сети и явно
воспроизводит dynamic DOM, Shadow DOM или iframe.

## Ограничения

Не добавляйте токены, персональные данные и случайные production‑страницы. Не
оставляйте пример, который не соответствует текущему API.

## Частые ошибки и проверка

Проверьте каждый JSON через `python -m json.tool`, ссылки — через
`check_docs.py`, стенд — через `browser_e2e.py`.

## Что обновить

При новом payload одновременно меняются API, схема агента и тест.
