# Инструкция для агента

## Цель папки

Python-ядро браузерного хаба, хранилище состояния, HTTP API, схема агента и командная строка.

## Как работать

`server.py` отвечает за HTTP и авторизацию, `store.py` — за состояние и очередь, `cli.py` — за интерфейс, `browser_agent.py` — за машиночитаемый контракт.

## Ограничения и частые ошибки

Не ослабляйте токен, не меняйте формат состояния молча и не разносите одну проверку по нескольким слоям. Сохраняйте стабильный идентификатор команды и идемпотентность результата.
