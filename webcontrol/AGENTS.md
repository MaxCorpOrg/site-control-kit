# Инструкция для `webcontrol`

## Назначение

Python‑хаб, протокол, транзакционное хранилище, сессии, артефакты и CLI.

## Основные файлы

`server.py` — HTTP; `store.py` — доменные переходы; `state_backend.py` —
SQLite; `protocol.py` — версии; `cli.py` — команды; `browser_agent.py` — схема.

## Разрешено и запрещено

Выделяйте сервисы через интерфейсы, сохраняя API. Не ослабляйте auth,
stale lease — просроченную аренду, идемпотентность и блокировку вкладки. Не
пишите секрет до маскирования.

## Частые ошибки

Гонка между истечением аренды и результатом, повтор опасного действия,
несогласованный JSON и SQLite, новая CLI‑команда без API.

## Проверка

Запустите `py_compile`, весь unit‑набор, mypy/Ruff изменённых файлов и
`browser_e2e.py` при изменении доставки.
