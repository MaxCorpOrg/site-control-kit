# Инструкция для агента

## Цель папки

Операторские сценарии запуска, браузерные обёртки и прикладные процессы Telegram.

## Как работать

Сначала определите контур: браузер, экспорт, приглашения или переносимый профиль. Общую логику на Python покрывайте тестами; оболочку держите короткой.

## Ограничения и частые ошибки

Не смешивайте безопасный экспорт с приглашениями. Не используйте неограниченные циклы, не печатайте токены и не полагайтесь на один формат окна. Для `.sh` запускайте `bash -n`.
