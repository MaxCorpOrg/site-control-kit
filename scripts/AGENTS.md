# Сценарии и вспомогательные программы

## Назначение

`scripts/` содержит E2E-стенд браузера, проверки репозитория, установку
тестового Chrome, операторские оболочки и отдельные Telegram-сценарии.

## Правила

- браузерный E2E не смешивайте с Telegram;
- загрузки проверяйте по официальному источнику и контрольной сумме, если она
  доступна;
- shell-сценарий должен завершаться с ненулевым кодом при ошибке;
- не зашивайте токен, IP, домашний путь и профиль пользователя;
- временные каталоги создавайте безопасно и очищайте.

Проверки: `bash -n` для shell, `py_compile` и профильные тесты для Python.
Частая ошибка — сценарий проходит только из корня репозитория без явной
проверки текущей папки.

После изменения пользовательского запуска обновите `USER_GUIDE_RU.md`; после
изменения E2E — отчёт в `docs/reports/` и статус проекта.
