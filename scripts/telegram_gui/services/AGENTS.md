# Сервисы графического интерфейса Telegram

## Назначение

Сервисы содержат сценарии приложения и координируют адаптеры без деталей GTK.

## Правила

- бизнес-решение должно тестироваться без открытия окна;
- состояние меняйте атомарно;
- отмену и повтор запуска обрабатывайте явно;
- не смешивайте экспорт, приглашение и portable-профиль в один сервис;
- ошибки переводите в понятный результат для UI.

## Проверка

После изменения добавьте модульный тест сервиса и запустите полный набор.
Частая ошибка — скрытое чтение глобального runtime вместо переданной
зависимости.

Связанные документы — инструкция Linux-продукта и `CHANGELOG.md`. Обновляйте
их при изменении сценария, формата результата или ограничения.
