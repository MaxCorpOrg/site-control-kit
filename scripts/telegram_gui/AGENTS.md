# Графический интерфейс Telegram

## Назначение

Папка содержит GTK-интерфейс для Telegram-сценариев. Это отдельная подсистема,
не часть браузерного протокола.

## Правила

- UI не должен напрямую менять runtime-файлы: используйте сервисы;
- долгую работу не запускайте в главном потоке;
- сообщения пользователю пишите по-русски и без технического стека;
- согласие пользователя и ограничения Telegram не обходите.

## Проверка и частые ошибки

После правок запускайте профильные тесты и ручную быструю проверку интерфейса.
Частая ошибка — заблокировать главный поток или обновить виджет из рабочего
потока. Не включайте изменения этой папки в PR браузерного ядра.

Связанный документ — `docs/LINUX_PRODUCT_INSTALL_RU.md`. Пользовательски
видимое изменение также фиксируется в `CHANGELOG.md` отдельного Telegram-PR.
