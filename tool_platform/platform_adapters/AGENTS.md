# Инструкция для агента

## Цель папки

Сменные адаптеры Linux, Windows и macOS для оконных и системных действий.

## Как работать

Общий контракт задавайте в `base.py`, платформенную реализацию — в отдельном модуле. Возможность должна честно сообщать, поддерживается ли она.

## Ограничения и частые ошибки

Не имитируйте поддержку пустой заглушкой. Не переносите команды одной операционной системы в общий слой.
