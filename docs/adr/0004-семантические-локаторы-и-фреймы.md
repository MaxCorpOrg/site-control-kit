# ADR-0004: Семантические локаторы и маршрутизация по фреймам

- Статус: принято
- Дата: 2026-07-24
- Область: браузерное расширение

## Контекст

CSS-селекторы хрупки на динамических сайтах. Полный HTML слишком большой для
агента, а одинаковые локальные ссылки в разных iframe неоднозначны.

## Решение

Добавить компактный семантический снимок. Каждый элемент получает:

- роль и доступное имя;
- значение и признаки состояния;
- локальную ссылку `eN`;
- `frame_id`.

Фоновый слой объединяет снимки фреймов и публикует ссылки `f<frame_id>:eN`.
Агент выбирает элемент по `ref`, роли, подписи, placeholder, тестовому
идентификатору, тексту или CSS.

Ноль или несколько совпадений считаются ошибкой. Если DOM заменил элемент,
`ref` восстанавливается только при единственном кандидате с тем же устойчивым
признаком.

Открытый Shadow DOM входит в поиск. Вложенные и кросс-доменные iframe
маршрутизируются через API расширения, если разрешены манифестом.

## Последствия

API становится устойчивее к перестройке DOM и дешевле по объёму контекста.
Закрытый Shadow DOM остаётся вне обычного DOM‑слоя и потребует отдельного
CDP‑адаптера.
