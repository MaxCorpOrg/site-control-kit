# ADR-0003: Сессии и блокировки вкладок

- Статус: принято
- Дата: 2026-07-24
- Область: параллельная работа агентов

## Контекст

Без владельца вкладки два агента могут одновременно менять одну страницу,
переключать URL и принимать результат другого сценария за свой.

## Решение

Каждый длинный сценарий открывает сессию с владельцем, сроком жизни и политикой.
Перед командой сессия блокирует точную пару `client_id + tab_id`.

Режимы:

- `exclusive` — единственный владелец;
- `shared_read` — совместное чтение без изменений;
- `operator_override` — явный перехват оператором с журналированием.

Heartbeat сессии продлевает её и блокировки. Истечение или закрытие освобождает
вкладки. Сессионная команда без точного клиента, вкладки или собственной
блокировки отклоняется.

Политика сессии ограничивает домены, ввод, загрузку файлов, отправку форм,
скачивание, CDP, число вкладок, время и диагностические данные.

## Последствия

Параллельные агенты получают явный конфликт вместо скрытой гонки. Для старых
несессионных команд совместимость сохранена, но строгой изоляции они не дают.
