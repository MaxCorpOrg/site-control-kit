# Инструкция для агента

## Цель папки

Здесь хранится русская документация по архитектуре, API, эксплуатации, безопасности и текущему состоянию проекта.

## Как работать

Сверяйте описание с кодом и используйте `TERMS_RU.md` для неизбежных английских терминов. Изменение протокола отражайте в `API.md`, расширения — в `EXTENSION.md`, архитектуры — в `ARCHITECTURE.md`, завершённой работы — в `PROJECT_STATUS_RU.md`.

## Ограничения и частые ошибки

Не переносите в документацию токены, личные данные и локальные пути пользователя. Не оставляйте английский заголовок без русского пояснения. Не описывайте возможность как готовую, если она не подтверждена кодом и проверкой.
