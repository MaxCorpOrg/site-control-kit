# Документация

## Назначение

`docs/` содержит технические источники правды, эксплуатационные инструкции,
решения архитектуры и исторические материалы.

## Главные файлы

- `API.md` — контракт;
- `ARCHITECTURE.md` — границы компонентов;
- `SECURITY.md` — модель угроз;
- `PROJECT_STATUS_RU.md` — только текущее состояние;
- `ROADMAP_RU.md` — план и зависимости;
- `TERMS_RU.md` — объяснение английских терминов.

## Правила

- пишите по-русски и объясняйте необходимый английский термин;
- не дублируйте большие разделы: ставьте ссылку на источник правды;
- изменение протокола всегда отражайте в `API.md`;
- изменение расширения — в `EXTENSION.md`;
- историю не накапливайте в `PROJECT_STATUS_RU.md`.

Проверка: `python3 scripts/check_docs.py`. Частые ошибки: устаревшая команда,
битая относительная ссылка и заявление о функции без тестового доказательства.
