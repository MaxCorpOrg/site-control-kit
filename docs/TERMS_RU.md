# Словарь терминов

В документации сначала используется русский смысл, затем неизбежный
английский термин.

| Термин | Пояснение |
| --- | --- |
| ack | Подтверждение, что расширение получило аренду команды. |
| artifact | Артефакт: файл с результатом, журналом или доказательством проверки. |
| backend | Внутренняя реализация интерфейса, например SQLite‑хранилище. |
| CDP | Chrome DevTools Protocol: протокол инструментов разработчика Chrome. |
| CI | Непрерывная интеграция: автоматические проверки в GitHub Actions. |
| CORS | Правила браузера, ограничивающие запросы между разными источниками. |
| dead letter | Команда с неопределённым исходом, которую опасно повторять автоматически. |
| delivery | Доставка одной команды одному браузерному клиенту. |
| E2E | Сквозная проверка всей цепочки от хаба до настоящего браузера. |
| failure bundle | Диагностический пакет одной ошибки. |
| HAR | Архив HTTP-обмена страницы: запросы, ответы и время сети. |
| heartbeat | Периодический сигнал, что клиент или сессия живы. |
| idempotency | Идемпотентность: повтор запроса не создаёт вторую логическую операцию. |
| iframe | Встроенный документ внутри страницы. |
| lease | Аренда команды на ограниченное время. |
| locator | Локатор: правило поиска элемента. |
| long polling | Долгий HTTP‑запрос, который ждёт событие вместо частого опроса. |
| LLM | Большая языковая модель, которая понимает и создаёт текст. |
| MCP | Протокол подключения инструментов и данных к ИИ-агенту. |
| MV3 | Manifest V3: формат расширений Chrome с непостоянным service worker. |
| outbox | Локальная очередь результатов, ещё не подтверждённых хабом. |
| p95 | Время, быстрее которого завершились 95% измерений. |
| policy | Политика: набор разрешений и ограничений сессии. |
| polling | Периодический опрос хаба. |
| proxy | Прокси: промежуточный сетевой сервер для соединения браузера. |
| ref | Короткая ссылка на элемент из семантического снимка. |
| retry | Повторная попытка. |
| runtime | Рабочие данные и процессы конкретного запуска. |
| service worker | Фоновый процесс расширения, который Chrome может остановить. |
| SDK | Набор библиотек и типов для программного использования API. |
| Shadow DOM | Изолированное DOM‑дерево веб‑компонента. |
| storage state | Cookies и веб‑хранилища, используемые для восстановления входа. |
| trace | Трассировка: подробная запись шагов выполнения и состояния. |
| TTL | Срок жизни сессии или блокировки. |
| UI | Пользовательский интерфейс: окна, кнопки и отображение состояния. |
| video | Видеозапись браузерной сессии для диагностики. |
| WAL | Журнал предзаписи SQLite, повышающий устойчивость транзакций. |
