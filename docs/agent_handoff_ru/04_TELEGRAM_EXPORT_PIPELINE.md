# Граница Telegram-подсистемы

Telegram-экспорт, приглашения, portable-профили и GTK-интерфейс — прикладные
подсистемы. Они могут использовать браузерный мост, но не входят в PR
браузерного ядра.

Перед Telegram-задачей:

1. найдите конкретный entrypoint через `rg "название команды" scripts`;
2. прочитайте `scripts/AGENTS.md` и более близкий `AGENTS.md`;
3. проверьте актуальный runtime вне репозитория;
4. не считайте старую выгрузку из `artifacts/` текущим состоянием;
5. соблюдайте согласие пользователя и не коммитьте персональные данные.

Текущий браузерный этап Telegram не менял. Возвращать его в работу следует
отдельным PR-C после слияния PR-A и PR-B.
