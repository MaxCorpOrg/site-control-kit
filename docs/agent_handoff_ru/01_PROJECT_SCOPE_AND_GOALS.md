# Границы и цель проекта

Цель Site Control Kit — безопасно давать ИИ-агенту управление реальным
браузером пользователя, не терять подтверждённые команды и не повторять
опасное действие вслепую.

В проект входят:

- локальный Python-хаб и HTTP API;
- CLI `sitectl`;
- расширение Chromium Manifest V3;
- тестовый браузерный стенд;
- отдельные Telegram, GUI и упаковочные подсистемы.

Браузерное ядро не должно зависеть от Telegram. Новый общий механизм сначала
оформляется как узкий интерфейс, затем подключается к прикладной подсистеме.
Полный план находится в [дорожной карте](../ROADMAP_RU.md).
