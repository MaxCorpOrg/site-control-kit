# Пакет передачи работы агенту

## Назначение

Файлы `00..10` дают короткую карту проекта и шаблон передачи незавершённой
работы. Полные контракты остаются в канонических документах `docs/`.

## Правила

- не копируйте сюда весь `PROJECT_STATUS_RU.md`, API или историю коммитов;
- обновляйте только изменившуюся карту или порядок действий;
- текущий риск и следующий шаг держите в `PROJECT_STATUS_RU.md`;
- Telegram описывайте отдельно от браузерного ядра.

Проверка: новый агент должен найти нужный компонент за один проход от
`00_START_HERE.md`. Частая ошибка — превращать handoff в бесконечный журнал.

Связанные документы: `START_HERE_AGENT_RU.md` и
`docs/PROJECT_STATUS_RU.md`. После изменения порядка входа сверяйте оба.
