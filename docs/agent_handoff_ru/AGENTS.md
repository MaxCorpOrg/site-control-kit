# Инструкция для агента

## Цель папки

Короткий пакет передачи контекста между агентами: устройство проекта, рабочий порядок, известные риски и очередь задач.

## Как работать

Читайте файлы по порядку `00..10`. Обновляйте только устойчивые сведения; оперативный отчёт пишите в `../PROJECT_STATUS_RU.md`.

## Ограничения и частые ошибки

Не копируйте сюда длинную историю запусков и не выдавайте старую находку за текущее состояние. Все термины объясняйте по-русски или ссылайтесь на `../TERMS_RU.md`.
