# С чего начать

Этот пакет — короткая карта, а не второй набор полной документации.

Прочитайте:

1. корневой `START_HERE_AGENT_RU.md`;
2. [текущее состояние](../PROJECT_STATUS_RU.md);
3. [архитектуру](../ARCHITECTURE.md);
4. локальный `AGENTS.md` нужной папки;
5. подходящий файл этого пакета.

Не переносите старые ветки целиком и не начинайте с checkpoint-файлов.
Браузерное ядро, документация и Telegram развиваются отдельными PR.

Текущая подтверждённая точка: браузерное ядро находится в PR-A, русская
документация — в следующем независимом PR-B. Ссылки и остаточные риски
зафиксированы в `PROJECT_STATUS_RU.md`.
