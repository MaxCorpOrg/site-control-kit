# Следующие шаги

Ближайший приоритет:

1. выделить сервисы хаба и адаптеры расширения без изменения API;
2. заменить частый polling на долгий запрос или событийный канал;
3. добавить устойчивые метки вкладок;
4. реализовать диалоги, загрузки и управляемые профили;
5. подключить тяжёлые артефакты как выключаемые модули;
6. только затем добавлять второй браузерный движок, SDK и MCP.

Сложность, зависимости, ожидаемый эффект и метрики находятся только в
[дорожной карте](../ROADMAP_RU.md). Не копируйте их сюда и не берите старый
старый список задач из контрольных точек без проверки кода.
