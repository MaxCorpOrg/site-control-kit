# Известные ограничения

Сейчас важны следующие ограничения:

- долгий запрос занимает поток локального HTTP-сервера до 25 секунд;
- сервисные интерфейсы добавлены, но доменная логика ещё сосредоточена в
  `store.py`;
- `background.js` всё ещё совмещает вкладки, фреймы, CDP и outbox;
- закрытый Shadow DOM недоступен обычному content script;
- системные страницы `chrome://` не управляются DOM-командами;
- HAR, trace и video ещё не реализованы;
- нет управляемых профилей, прокси и полного API скачивания и диалогов;
- нет Firefox/WebKit-адаптера, SDK и MCP;
- старый режим без сессии сохранён для совместимости и не даёт владения
  вкладкой.

Перед исправлением сверяйте список с
[текущим состоянием](../PROJECT_STATUS_RU.md): этот файл только объясняет
категории риска и не является журналом живых наблюдений.
