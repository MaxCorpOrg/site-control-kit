# Состояние и артефакты

Хаб хранит транзакционное состояние в SQLite; прежний JSON мигрируется с
резервной копией. Точный runtime-каталог показывает:

```bash
python3 -m webcontrol runtime-env --format json --no-create
```

Артефакты сессии лежат в её `artifact_dir`. Основные файлы:

- `session.json`;
- `commands.jsonl`;
- `events.jsonl`;
- `errors.jsonl`;
- диагностические пакеты ошибок.

Не коммитьте runtime, SQLite, браузерный профиль, cookies и токены. Перед
диагностикой используйте вывод с сокрытыми секретами. Перед изменением схемы
создайте backup и тест миграции. Подробности — в [API](../API.md) и
[безопасности](../SECURITY.md).
