# Приёмка GNOME 12 мая 2026 года

Историческая проверка закрыла запуск Linux-пакета из обычного меню приложений
Ubuntu GNOME для линии `45c25e4`.

## Окружение

- Ubuntu 24.04.4 LTS;
- GNOME/X11;
- Python 3.12.3;
- пакет `telegram-username-collector` версии `0.1.0`.

## Доказательства

- переустановка `.deb` прошла успешно;
- диагностика из `/tmp` показала installed-режим, корректные XDG-пути,
  готовое расширение и рабочий GTK;
- `gtk-launch telegram-username-collector` открыл окно;
- оператор отдельно подтвердил запуск из меню приложений;
- runtime-файлы не попали в `/opt`.

Единственным предупреждением было `hub_reachable=0`: хаб во время этой части
проверки не запускался.

## Итог

Разрыв приёмки стандартного GNOME-меню был закрыт. Вывод относился только к
ветке повторного базирования 12 мая и не является текущим релизным статусом.
Актуальное состояние находится в `docs/PROJECT_STATUS_RU.md`.
