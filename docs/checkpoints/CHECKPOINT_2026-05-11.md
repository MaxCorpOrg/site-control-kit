# Контрольная точка 11 мая 2026 года: Windows

Исторический этап проверял хаб, CLI, wrappers и расширение на реальной
Windows-машине.

## Результат

- хаб запускался через Windows-сценарий без traceback;
- `browser.cmd status` и `browser.cmd tabs` видели Edge-клиент;
- `runtime-env` корректно показывал принятый старый runtime;
- Telegram GUI на Windows завершался понятным сообщением, потому что GTK не
  входит в поддерживаемый Windows-контур;
- устранена зависимость Python-кода от обязательного POSIX home и execute bit;
- полный набор: 303 теста.

## Ограничение

После одного прогона клиент расширения стал неактивным. Перезапуск Edge с
распакованным расширением восстановил связь; изменения кода не
потребовались. Чистый project-local runtime на машине со старым
`%USERPROFILE%\.site-control-kit` тогда не проверялся.

Точные старые команды и локальные пути доступны в истории Git. Актуальный
Windows-сценарий находится в `docs/WINDOWS_SMOKE_HANDOFF_RU.md`.
