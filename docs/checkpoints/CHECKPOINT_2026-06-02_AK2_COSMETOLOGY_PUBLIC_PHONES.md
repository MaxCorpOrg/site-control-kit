# Контрольная точка 2 июня 2026 года: открытые телефоны AK2

Исторический живой прогон проверял сбор открыто опубликованных телефонов через
Telegram GTK-интерфейс и основной `tdata`-источник.

## Найдено

Помощник собирал телефоны только из `about` пользователя, хотя интерфейс и
документация обещали также описание чата, закреплённые сообщения и историю.
Это расхождение было исправлено в следующей контрольной точке.

## Доказательства этапа

- несколько чатов обработаны пакетно;
- повторный запуск одного чата дал новые номера;
- результаты сохранялись в Markdown, TXT и JSON;
- `default_user` не менялся;
- персональные runtime-файлы не предназначались для Git.

Этот файл фиксирует только исторический диагноз, а не текущие возможности
Telegram-сборщика.
