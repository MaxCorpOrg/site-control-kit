# Контрольная точка 12 июля 2026 года

Исторический этап стабилизировал установленный Linux-пакет Telegram Username
Collector после анализа живого интерфейса и журналов.

## Основные изменения

- wrappers запускают Python из корня установленного приложения;
- диагностика использует `SITECTL_PRODUCT_APP_ROOT`;
- JSON-вывод `runtime-env` скрывает токен по умолчанию;
- журнал интерфейса фиксирует старт и обновление профилей;
- `Ctrl+C` завершается кодом 130 без traceback;
- добавлен импорт Telegram API ID/Hash для выбранного профиля;
- быстрые шаблоны чатов отделены от доказательства реального доступа;
- API Hash не записывается в журнал.

## Проверки

- полный набор: 335 тестов успешно, 2 пропущены;
- профильные Telegram-тесты и `py_compile` прошли;
- `scripts/verify.sh` прошёл;
- содержимое пакета проверено через `dpkg-deb`;
- `.deb` реально переустановлен;
- диагностика из `/tmp` подтвердила installed-режим;
- окно, импорт API и управление шаблонами проверены вручную.

`hub_reachable=0` был ожидаем: хаб в этом smoke-прогоне не запускался.
