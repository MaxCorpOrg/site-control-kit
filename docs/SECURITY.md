# Безопасность

## Аутентификация
- Хаб принимает общий токен.
- Токен должен совпадать у хаба, CLI и расширения.

Быстрый локальный режим:
- токен по умолчанию `local-bridge-quickstart-2026`
- использовать только на личной локальной машине.

Для безопасного режима:
- обязательно задайте свой сильный токен (`SITECTL_TOKEN`).

## Риски
- Если токен утечёт, локальные команды можно отправлять от чужого процесса.
- Если открыть хаб наружу без защиты, возможен несанкционированный доступ.
- `run_script` может выполнять произвольную логику в контексте страницы.
- Расширение имеет доступ ко всем обычным страницам и разрешение `debugger` для CDP; это высокий уровень доверия.
- `state.json` и локальная очередь расширения могут содержать результаты команд и фрагменты данных страницы.
- Широкий CORS и поддержка токена в строке запроса допустимы только в текущем локальном доверенном режиме.

## Рекомендации
1. Держать хаб на `127.0.0.1`.
2. Использовать длинный случайный токен.
3. Регулярно менять токен.
4. Не публиковать хаб напрямую в интернет.
5. Если нужен удалённый доступ — только через защищённый обратный прокси, дополнительную аутентификацию и TLS либо через SSH-туннель.
6. Не хранить чувствительные секреты в командах без необходимости.
7. Не публиковать наружу noVNC; по умолчанию слушать только `127.0.0.1`.
8. Перед снимком экрана или трассировкой проверять, нет ли на странице секретов.
9. Не передавать `runtime/`, `tdata`, профили браузера и Telegram в репозиторий.

## Данные и приватность
- `state.json` содержит историю команд и результаты.
- `chrome.storage.local` расширения временно хранит неотправленные результаты.
- Для чувствительных сценариев задавайте ограниченный срок хранения и очищайте данные только после резервной копии нужных доказательств.

## Граница доверия

Текущая версия — локальный инструмент одного доверенного оператора. Она не является песочницей и пока не предназначена для прямого многопользовательского доступа. До такого режима нужны отдельные учётные данные агента, ограничения возможностей, правила доменов, скрытие секретов и шифрование состояния.

## Правовое использование
Используйте только там, где у вас есть право автоматизировать действия.
