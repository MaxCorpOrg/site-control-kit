## Текущий риск

Сервисная граница добавлена, но большая часть доменной логики всё ещё физически
находится в `webcontrol/store.py`. `extension/background.js` продолжает
совмещать вкладки, фреймы, CDP и outbox.

Другие ограничения:

- HAR, трассировка и видео пока только поля политики;
- нет управляемых изолированных профилей авторизации;
- нет прокси и полного API скачивания и диалогов;
- один хаб — один писатель SQLite;
- Firefox/WebKit и Playwright‑адаптеры отсутствуют;
- Python SDK и MCP отсутствуют;
- старые команды без сессии остаются режимом совместимости.

## Следующий приоритет

P1: вынести `PolicyEngine` и `StateRepository` за готовые сервисные интерфейсы
без изменения публичного API. Затем выделить из `background.js` `TabRouter`,
`CdpAdapter` и `ResultOutbox`.

После этого:

1. устойчивые метки и реестр вкладок;
2. управляемые профили и storage state;
3. скачивания, диалоги и прокси;
4. HAR, трассировка и видео;
5. Playwright‑адаптер и второй браузер;
6. Python SDK и MCP.

Подробности и зависимости — в [дорожной карте](ROADMAP_RU.md).
