## Текущий риск

Крупные файлы `webcontrol/store.py` и `extension/background.js` совмещают
несколько ролей. Поведение покрыто тестами, но дальнейшее расширение без
выделения сервисов снова увеличит связанность.

Другие ограничения:

- HAR, трассировка и видео пока только поля политики;
- нет управляемых изолированных профилей авторизации;
- нет прокси и полного API скачивания и диалогов;
- один хаб — один писатель SQLite;
- Firefox/WebKit и Playwright‑адаптеры отсутствуют;
- Python SDK и MCP отсутствуют;
- старые команды без сессии остаются режимом совместимости.

## Следующий приоритет

P1: выделить интерфейсы `CommandService`, `SessionService`, `PolicyEngine`,
`BrowserAdapter`, `CdpAdapter` и `ResultOutbox` без изменения публичного API.
Одновременно сократить задержку доставки с polling около двух секунд до
событийного или long‑polling механизма.

После этого:

1. управляемые профили и storage state;
2. скачивания, диалоги и прокси;
3. HAR, трассировка и видео;
4. Playwright‑адаптер и второй браузер;
5. Python SDK и MCP.

Подробности и зависимости — в [дорожной карте](ROADMAP_RU.md).
